# Website change and release instructions

- This repository is the source for the cyprus-water-filter Vercel project in maximconstantinou14-2429s-projects.
- Use a new feature branch and a pull request targeting main for requested website changes.
- Run relevant catalogue and translation checks and a production build before handing over the preview.
- Wait for the automatic Vercel Preview deployment and give Max its preview URL and a concise description of the changes.
- Do not merge a website change into main, push it directly to main, or deploy it to Production until Max explicitly approves the preview or explicitly requests release.
- After an approved merge, verify that the Production deployment succeeded for the merged commit.
- Never commit credentials, environment files, dependencies, or generated build output.
- Preserve the original source ZIP as a historical backup; edit the unpacked repository source.
