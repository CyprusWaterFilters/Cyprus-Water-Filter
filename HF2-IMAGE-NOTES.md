# HF2-S product imagery

The user clarified that the red-label cartridge photography belongs to the HF2-S (HFS) range, rather than HF2. The website now uses these assets for HF2-S only. HF2 returns to the existing type-led placeholder until matching HF2 photography is supplied.

The three final presentation mockups were made with the built-in Image Generation tool by precisely editing the corrected, proportion-matched red-label images. The product geometry, framing, pale blue studio background, shadow, FLUUX branding, and `Water Filter` subtitle were preserved. Only the model names were changed to `HF2-10S`, `HF2-15S`, and `HF2-17S`. No technical claims or certifications were added.
